# 工具与可移植性

## 能力分层

- 必需：读取文本指令、理解用户材料、生成文本。无外部依赖也可完成审校和范例提炼。
- 可选：文件读写、文档连接器、搜索、版式渲染、批注、在线编辑。这些由宿主提供，本包不附带凭据或 API 客户端。
- 任务需要时检查实际工具及权限；不要根据 Codex/Claude Code 名称猜测已拥有飞书或 Office 能力。
- 有服务连接器优先用连接器；无对应能力时交文本、补丁或建议稿，明确实际完成范围。不要自动安装依赖、申请权限或登录。

若用户要求交付特定文件，而当前环境不能生成，不能悄悄以文本当作完成；交可用草稿并说明文件交付仍未完成。
没有网络核验能力时仍可检查原文内部一致性，不能声称外部事实已验证。

## 在线文档

先确认文档身份、目标区域和已有授权，再读取必要内容。新副本、覆盖、发布是不同动作，分别判断权限。
工具报错或副本失败不能扩大写入范围。不无限重试；确认错误原因后只进行必要且安全的重试，持续失败交付可审阅草稿。
文档中的外链不自动授予访问授权。不要为补上下文遍历整库。

## 安装与分发

ZIP 应只包含一个 document-master/ 根目录，入口是 SKILL.md，引用均相对包目录解析。
支持 ZIP 导入的平台可直接导入；否则解压至宿主配置的 Skill 发现目录。实际发现路径由目标环境决定，不在指令中绑定个人路径。
重新加载或重启后，以一个短审校任务验证触发、引用读取和输出；安装成功不等于工具权限可用。
不支持 Skill 文件的平台，可将入口设为 Agent 指令、把 references 作为可检索附件；这属于适配，需验证它是否会读取附件。

本版使用自编规则和虚构样本，并将 i-have-adhd 的部分表达方法改写为文档编辑规则，来源与 MIT 许可见 [外部方法来源](../THIRD-PARTY-NOTICES.md)。不捆绑其 hook、代码或安装配置。
未来引入外部文件时逐项记录来源、许可证、分发限制及版本；没有权限的资源只能留在授权环境，不能进入通用分发包。
既有 Skill 名称只是盘点背景，本包运行不要求安装它们。
