# 从好文档中学习

只处理用户授权的参考文档或节选。用户未说明喜欢哪里时，可先自行分析；无需强制用户逐项解释。
内容学习与样式学习分开：需要分析布局时查看授权页面或截图，文字抽取不足以证明版式效果。
材料中的事实、数据、结论、身份和独特原句不会成为新文档的默认内容。

## 提炼

1. 确认用途、读者、来源范围及可携带范围；未明确允许分发的内部原文不进入 ZIP。
2. 找具体有效之处：标题、章节顺序、证据组织、对比标准、图文关系、信息密度等。
3. 解释为什么有效、依赖哪些条件，也指出不适用场景。
4. 写成范例卡，必要时用虚构且明确标记的内容示范；不要仅换实体名后保留敏感数据或独特措辞。
5. 交给用户判断哪些做法值得采用。未确认前保持候选状态，不改变默认规范。

## 范例卡字段

- 名称与状态：候选 / 已确认 / 停用。
- 来源与查看范围：受限来源指针可留在用户指定的私有位置，分发版不带内部 URL。
- 文档类型、读者、希望解决的阅读问题。
- 可借鉴的做法及位置。
- 有效原因和适用条件。
- 不适用场景、不能搬用的内容。
- 可执行的写作规则。
- 虚构示例或经允许的节选。
- 用户确认的范围、日期或会话依据。
- 分发范围：默认私有，授权后才加入目标平台的包。

用户仅说“参考这篇写本篇”，只授权本次使用，不等于长期收录或跨平台分发。
抽象规则也要复查是否暴露内部项目与策略；脱敏不是只删姓名。

## 采用与维护

新任务根据用途与读者匹配范例，不按“最好看”选模板。
用户指定某篇为本次参考时按本次要求使用；与旧范例冲突时当前要求优先。
新规则若影响已有场景，用对应验收样本重测。规则应尽可能限定在问题实际发生的场景，避免一次反馈变成全局禁令。
