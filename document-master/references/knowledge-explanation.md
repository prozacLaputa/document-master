# 知识讲解与技术分享

适用：帮助读者建立概念、理解原理或辨析方法的教程、入门分享、知识说明。
不替代技术方案评审、操作手册、汇报或个人文章。先识别读者已有知识与本次学习目标，能从材料推断就不重复问。

## 学习路线
围绕读者会遇到的问题推进：熟悉场景 → 新概念 → 运作过程 → 限制与应用，是可选路线而非固定章节。
全景型分享适合从生活场景或业务演进切入，再展示问题与技术关系。
专题型长文在首屏说清核心认识。概念需要背景才能理解时，可先用一个短段写读者熟悉的具体困惑，再用简短结论块回答；随后逐层讲机制、比较和边界。已有稿件的开场能完成这个任务时沿用原样。必要时补阅读路线，目录承担导航。结论块与强调方式遵循 [编辑规范](editorial-rules.md)。
短说明不必加路线图；不知道的前提明确写出，不能虚构受众背景。
类比仅解释有对应关系的部分，说明类比在哪些地方失效，不把类比当证明。

## 用同一个问题带着读者往下走

- 长文可选择一个有来源的案例或明确标记的模拟场景贯穿。首次交代人物或系统、动作和困惑，后文每次回到案例都解释一个新机制、状态变化或失败条件。换例子应有新的教学用途，例如补充另一种边界或应用，避免每节重新铺背景。
- 概念按理解所需的顺序引入。首次出现先说它在当前场景里做什么，再给术语；读者熟悉的技术可作为参照，具体交代相同点与不同的保证。概念较多时用速查表帮助回看，正文仍要解释它们如何一起工作。
- 机制讲解写清触发条件、发生的动作、结果及成立边界。将“系统完成了哪一步”落到读者看到的状态或下一步能做什么，重要限制放在对应判断附近。一次成功、性能指标或中间确认能证明的范围要准确。
- 小标题尽量对应具体阅读问题。段落之间用问题的推进连接，例如先解释正常过程，再解释在哪一步失败、为何会出现看似矛盾的结果。短段落也应有完整因果，不把每句话拆成项目符号。
- 自然表达来自具体主体、动作和后果。保留必要术语与技术细节，用案例解释抽象词；不靠连续设问、反复“通俗地说”、密集类比或每节小结制造口语感。

## 根据阅读问题选择版式

| 阅读问题 | 可选形式 | 使用条件 |
|---|---|---|
| 各部分是什么关系 | 关系图 + 就近的解释 | 图承担关系，正文补条件，不逐字重复 |
| 两个概念容易混淆 | 对称分栏 | 统一比较维度、粒度和顺序；内容太长改上下排列 |
| 一件事如何发生 | 一个具体例子 + 流程 | 事件、状态、方向明确；异常分支不能被美化掉 |
| 多种方案如何取舍 | 比较表 | 候选真实，维度有用，优缺点有依据，缺证据不填猜测 |
| 方法为何有必要 | 失败场景 → 原因 → 应对 | 真实案例有来源，构造案例明确标记 |
| 哪个条件最容易漏 | 短提示块或图注 | 一块只强调一个重点，不靠颜色单独传递含义 |

按基础排版主动选择有用的图表，不要求全部形式出现；先写清要讲的内容，再决定视觉结构。
图、表、正文只有各自增加信息时才同时保留，不能机械执行“每节一图一表”。

通用段落长度、层级、留白、强调与图文对齐均遵循 [基础排版](layout-basics.md)，不只在知识讲解时启用。以下是教学组织的补充。

## 具体规则
- 分栏用于同屏对应或比较，不用于平分无关段落。需要比较时保持相同问题顺序。
- 图示贴近首次解释它的段落。图前的标题或短引导交代情境和要解决的问题，不先把图中完整步骤讲一遍；图中承担参与者、关系、状态或先后过程。图后解释原因及容易误解的边界，例如省略的步骤、失败窗口或适用条件，不再顺着图复述一遍；解释已经充分时直接进入下一段。
- 选择图的形态跟着理解难点走。正常与异常用对应布局，先后与确认可用时序或按阶段展开的泳道，层级与职责用分层图，数量变化用有依据的示意或曲线。图表中的术语、动作与正文一致，不能让简化图承诺正文没有的能力。图内不塞满整段说明，细节多时拆图或移到邻近正文。
- 版式层次优先靠语义标题和留白，颜色与加粗只强调少数关键信息，按已确认的强调规则执行，不照搬范文的全部色板。
- 比较表选读者需要判断的共同维度，机制、收益与代价就近对应，避免只列优点。连续因果保留在段落或过程图里，不拆散塞入术语表。
- 代码、公式和案例让读者能走通一次过程。算例先交代假设、单位与条件，再解释结果意味着什么；伪代码明确标记，不凭例子宣称性能提升或通用保证。
- 提示块与引用块区分：自己写的结论不伪装成外部引文。
- 列表编号连续，标题层级一致；交付前清除无意留下的占位词，待核实项则明确保留。
- 窄屏上比较分栏依阅读顺序转为单栏；表格保留表头和对应关系，可横向滚动。不能为适配窄屏删掉代价和条件。
- 纯文本环境用标题与比较表表达同样的信息，说明视觉限制，不假装已有图。

## 证据范围
正文直接写影响读者理解的边界，例如“一致所需时间尚未确定”。资料搜集、核验进度和“材料没有提供某数据”通常放交付说明；当正文没有提出相关主张时，也不额外罗列证据缺口。缺口确实影响核心判断时，应写清它使哪个结论暂时不能成立。
读取文档样式可以确认分栏、列宽、强调方式和图文位置；不能单凭 XML、图片替代文本或画板占位推断画板美术质量。
只有实际查看渲染后，才评价拥挤、溢出、文字可读性和页面观感。
借鉴表达形式不等于接受范例的事实结论。参考原文、图片和内部链接不随本包携带。
