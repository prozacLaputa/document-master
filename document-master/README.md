# 文档大师 0.6.0

可移植的文档整理与审校 Skill。唯一入口是 [SKILL.md](SKILL.md)。
支持诊断、修订、新稿、参考文档学习及授权范围内的归档建议；按文档类型选择写法。
核心文本流程无需外部 Skill、第三方库或联网。在线写回、文件生成和渲染取决于宿主工具。

使用：将 ZIP 导入支持 Skill 上传的环境，或解压到该环境配置的 Skill 发现目录，再重新加载。
可用提示：“用文档大师审校下面的技术方案，保留原意，交修订稿、关键改动和待核实项。”
实际路径、权限和工具接入见 [工具与可移植性](references/tools-and-portability.md)。

默认保留原稿；改变结论、重要删除、覆盖与发布需要确认。
参考文档不会自动成为长期偏好，也不会自动进入跨平台包。
本版未携带真实文档、内部链接、账号、个人语料或第三方 Skill 副本。

本版默认主动用表格对照、画板解释关系，并配置彩色重点与必要的高亮块；父标题与首个子标题之间不插空段。原生示范见 [说明](examples/native-layout.md)。

本包将段落尺度、层级、留白、列宽和强调提升为所有文体的基础排版检查；按信息关系迁移范例，不因题材不同而跳过。继续执行结论先行和信息密度检查。借鉴方法及许可见 [来源说明](THIRD-PARTY-NOTICES.md)。
[知识讲解规范](references/knowledge-explanation.md) 与 [虚构图文示范](examples/knowledge-demo.html) 继续保留，示范不是统一模板。

版本状态：试用迭代版，可供审阅及试用；尚未在其他云平台上验证。
验收材料见 [行为验收](evals/cases.md)。结构检查不证明模型行为稳定。
