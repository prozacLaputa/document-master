# 原生图表与高亮示范

这是完全虚构的借书室示范，不含参考文档的事实、链接、图片或原文。

- [文档 XML](native-layout.xml)：包含结论提示块、三张原生表格、一张流程画板、彩色短语和结尾提醒。
- [流程 SVG](demo-flow.svg)：标明正常交接条件，并区分记录冲突、未找到实物两条异常分支。

两文件放在同一目录，由支持对应 XML 的飞书工具读取。XML 是宿主适配示例，不是所有 Agent 通用接口；其他宿主按信息关系重建，纯文本宿主使用表格和步骤说明。

## 为什么这样排

开头先给核心判断；第一张表区分两类记录，第二张表比较工具，第三张表对应状态与动作。三张表各解决不同问题，不逐行在正文复述。流程图标明正常条件和两条异常分支；正文补充按书号核对的要求。绿色标注可继续或明确写出的示例建议，红色标注暂停；含义也用文字表达，不靠颜色单独传达。

章标题与首个子标题之间没有空段；同级小节用原生间距分组。表头统一浅灰，标签列窄、解释列宽。该例的字号、列宽、配色和组件数量不是所有文档的固定配额。
