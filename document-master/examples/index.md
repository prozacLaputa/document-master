# 范例目录

- [方案对比示范](synthetic-comparison.md)：虚构示范，仅用于解释如何提炼写法；不是用户确认的默认模板。

新增真实范例前执行 [范例学习](../references/reference-learning.md)。候选范例不自动生效，内部来源默认不随包分发。

- [跨文体微调示范](layout-transfer.md)：段落、标签、列宽与强调在不同材料中复用。

- [原生图表与高亮示范](native-layout.md)：虚构内容，附 XML 与 SVG；展示本版默认排版选择及实际验证范围。

- [方案结论与工作记录反例](decision-not-activity.md)：区分可行性判断、证据结果和实施过程。

- [技术方案完整示例](technical-solution.md)：虚构的报名防重方案，展示判断、取舍、总分设计和验证边界。
